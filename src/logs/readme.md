# Logs

Esta carpeta contiene los registros generados durante la ejecucion del pipeline.

- ingesta.log : Registro de la ingesta de imagenes del dataset
- preprocesamiento.log : Registro del preprocesamiento de imagenes
- entrenamiento.log : Registro del entrenamiento del modelo YOLOv8s
- evaluacion.log : Registro de las metricas de evaluacion del modelo
