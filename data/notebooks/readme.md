# Notebooks

Esta carpeta contiene los experimentos y el código de entrenamiento del modelo.

- exploracion_datos.ipynb : Análisis exploratorio del dataset de imágenes

- evaluacion_modelo.ipynb : Evaluación del modelo con métricas de desempeño
